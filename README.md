# Pharmacy Health

This repository contains the implementation of two core business processes for a pharmacy information system:

- **Supplier Management**
- **Report Management**

These modules are developed to support digital transformation within a pharmacy, ensuring better control over suppliers and improved reporting capabilities.

## Project Overview

The system is designed to streamline daily pharmacy operations by digitalizing and automating key workflows. The implemented functionality includes:

- Secure user authentication
- Management of supplier data and supply chains
- Generation and export of business reports for pharmacy management
- Role-based access for pharmacists, administrators and managers

## Architecture Overview

The application is modular and component-based. Implemented components include:

- **User Management**
- **Supplier Management**
- **Report Management**

Each component is connected via well-defined interfaces and is aligned with system roles and responsibilities.

## Benefits

- Simplified and centralized supplier tracking
- Automated reporting for faster insights and analytics
- Enhanced security through controlled user access
- Built following ITIL principles for reliability and scalability

## Technologies Used

- UML for modeling and documentation
- GitHub for version control
- Node.js – for backend development
